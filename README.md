# BATULU
---
## 项目介绍
BATULU是一个应用强化学习的游戏框架，它允许用户使用强化学习算法来训练游戏AI。BATULU提供了一套完整的API，包括环境定义、动作空间、奖励机制等，用户可以根据自己的需求来定义游戏环境和AI的行为。当前仍处在开发阶段

## 玩法介绍
BATULU的玩法主要为回合制战棋玩法，分为两个阶段
### 决策阶段
两边玩家同时决定本回合的行动
#### 移动
玩家手动设定移动路径，由单位移动力决定移动距离
#### 攻击
攻击视野内一单位，造成（基础攻击+骰子点数-防御）伤害
#### 防御
若受到伤害，仅受到（骰子点数-防御）伤害，并对攻击方造成（骰子点数）伤害
#### 技能
释放技能
### 判定阶段
依次摇骰子，对以下情况进行说明
#### 攻击移动单位
初始造成一次伤害，其每移动三格再进行一次伤害
#### 攻击正在攻击单位
使对方最多进行一次伤害
